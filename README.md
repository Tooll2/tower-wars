# ⚔️ Shango Tower Wars (1v1 PvP Real-Time Strategy)

> Классическая браузерная PvP Tower Wars игра в реальном времени, вдохновленная кастомными картами Warcraft 3.

- 🌐 **Играть онлайн**: [https://tooll2.github.io/tower-wars/](https://tooll2.github.io/tower-wars/)
- 💻 **Репозиторий**: [https://github.com/Tooll2/tower-wars](https://github.com/Tooll2/tower-wars)

---

## 🎮 Основные механики

1. **Онлайн 1v1 PvP**: Без регистрации и паролей. Создайте 4-значную комнату и передайте код сопернику.
2. **Строительство башен (2×2 клетки)**: Стройте лабиринты, удлиняя путь крипов соперника.
3. **Призыв крипов (12 видов юнитов)**: Каждый отправленный крип увеличивает ваш постоянный доход (Инком), который выплачивается каждые 15 секунд.
4. **Согласованная скорость**: Скорость игры равна `Min(Ваша скорость, Скорость соперника)`. Отображается выбор обоих игроков в реальном времени.
5. **Симметричная карта (70×66)**: 4 равных контрольных зоны (11×11), центральная непроходимая стена (18×42).
